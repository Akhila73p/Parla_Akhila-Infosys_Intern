
# Wildlife Population Intelligence System

## Infosys Springboard Internship 7.0

### Project Description
The Wildlife Population Intelligence System is an AI-powered platform that helps identify wildlife species, estimate population size, monitor biodiversity, detect endangered species, and analyze habitat health using image recognition, bioacoustic analysis, and machine learning.

### Tech Stack
- Frontend: React.js
- Backend: FastAPI (Python)
- Database: PostgreSQL + MongoDB
- AI/ML: YOLOv8, TensorFlow, PyTorch, OpenCV
- Deployment: Docker, AWS/Azure
